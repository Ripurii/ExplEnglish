# Content To-Do List

Tracks which lessons/activities are done vs. still in progress. Each post in
`_posts/` has a `status:` front-matter field (`"finished"` or `"ongoing"`,
omitted entirely for anything not started yet). Only posts with
`status: "finished"` show up in site listings (Home, Library, Grammar,
Latest) — everything else is still reachable by direct link (useful for
testing while building it out), just hidden from browsing until it's ready.

To publish something once it's done: set `status: "finished"` in its front
matter, then update this file.
